# ⚡ Signature Studio — Aesthetic & Futuristic Email Signature Architecture

A modern, aesthetic, and futuristic email signature generator and avatar creator built for professionals, developers, and organizations. Zero dependencies, 100% email client-safe, and instantly deployable to **Vercel**, **GitHub Pages**, or **Netlify**.

---

## ✨ Features

- **6 Pixel-Perfect Email Layouts**:
  - `Executive Side` (Classic side-by-side with vertical accent divider)
  - `Modern Banner` (Top header accent bar with dynamic column alignment)
  - `Corporate Left Stripe` (Solid continuous brand stripe)
  - `Minimalist` (Ultra-clean, compact, high-efficiency)
  - `Badge Card` (Boxed horizontal card with border frame)
  - `Centered Formal` (Symmetrical layout for academic and executive use)
- **Aesthetic NextGen UI**:
  - Default **Futuristic Light Mode** with crisp contrast and glassmorphic translucent panels.
  - Optional **Cyber Dark Mode** with deep space gradient aurora meshes.
  - Interactive **Light / Dark Mail Client Tester** to preview signatures against both light and dark email backgrounds before copying.
  - 100% responsive on smartphones (iOS & Android) with a dedicated mobile floating action bar.
- **Precision Color Engine**:
  - Full custom Hex color picker for primary and secondary brand colors.
  - 12 curated corporate & modern preset palettes.
- **Universal Email-Safe Typography**:
  - Extensive font support across Sans-Serif, Serif, and Monospace families (Arial, Segoe UI, Calibri, Trebuchet MS, Georgia, Times New Roman, Consolas, System Native).
- **Precision Dimension Sliders**:
  - Individual sliders for profile photo, company logo, name, title, contact rows, social icons, and divider thickness.
  - One-click **"Reset to Recommended"** restore button.
- **Smart Cloud & Google Drive Resolver**:
  - Automatic Google Fife CDN resolver (`lh3.googleusercontent.com/d/{id}`) with multi-level fallbacks.
  - Direct computer file upload for profile photos and organization logos.
- **Integrated Avatar Forge (Round Photo Studio)**:
  - Drag and precision zoom to center portraits.
  - Metallic borders (Rose Gold, Classic Gold, Royal Purple, Ocean Navy, Silver Metal).
  - One-click direct application to Signature Studio or download in 300×300 / 600×600 PNG.
- **1-Click Export & Clipboard Integration**:
  - Formatted rich-text clipboard copy for direct paste into Gmail, Outlook, and Apple Mail.
  - Raw HTML copy and standalone `.html` signature file download.

## 🚀 Instant Deployment on Vercel

### Option 1: Import via GitHub (Recommended)
1. Push this repository to your GitHub account (e.g., `https://github.com/Rafi-Shah/signature-studio`).
2. Go to [vercel.com](https://vercel.com/) and sign in with your GitHub account.
3. Click **"Add New..."** ➔ **"Project"**.
4. Select your **`signature-studio`** repository and click **"Import"**.
5. Keep default settings (Framework Preset: **Other**) and click **"Deploy"**.
6. Your live site will be ready in seconds with a free `.vercel.app` domain!

### Option 2: Deploy via Vercel CLI
```bash
# Install Vercel CLI globally
npm i -g vercel

# Deploy directly from your project directory
vercel
```
